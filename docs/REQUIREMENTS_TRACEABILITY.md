## Intentional Prototype Simplifications (Transparently Documented)
1. **Telephony**: High-fidelity deterministic simulator with configurable failure modes and timing rather than paid Twilio/SIP trunking.
2. **EHR Connectivity**: Realistic in-memory/relational mock implementing a pluggable `EHRService` interface rather than an actual Epic/Cerner FHIR server.
3. **Database Portability**: Dual-engine architecture: Zero-setup SQLite (WAL mode, foreign keys, row concurrency checks) + full PostgreSQL with pgvector schema migrations and Docker configuration.
4. **Vector Store**: Pluggable vector store interface supporting pgvector in PostgreSQL and embedded cosine-similarity with numpy for instant zero-dependency local testing.
5. **AI Provider Fallback**: Provider-agnostic abstraction (`AIProvider`) supporting OpenAI/Gemini/Anthropic API keys via environment variables, along with a deterministic local clinical rule & heuristic LLM fallback engine so test suites and offline evaluations execute 100% reliably without requiring external credits or incurring network flakiness.
